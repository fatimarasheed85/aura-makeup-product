# Aura Beauty Luxury E-Commerce - Shopify OS 2.0 Theme

A premier, editorial Shopify Online Store 2.0 theme built for **Aura Beauty**, strictly following the **Radiant Dew Skin** design system and Stitch MCP luxury specifications.

## Theme Architecture & Sections

- **Shopify Online Store 2.0 Architecture:** JSON templates, dynamic sections, and blocks.
- **Radiant Dew Skin Design System:** Curated warm cream (`#FDFBF7`), cashmere blush (`#DFB7A7`), deep charcoal (`#2B2421`), Playfair Display headings, and Plus Jakarta Sans UI.
- **10 Core Pages & Sections:**
  1. **Home Page** (`templates/index.json` + `hero-banner.liquid`, `featured-collection.liquid`)
  2. **Product Detail** (`templates/product.json` + `main-product.liquid` with interactive gallery & rituals)
  3. **Collection Catalog** (`templates/collection.json` + `main-collection.liquid` with sticky filters)
  4. **Shopping Bag & Cart Drawer** (`templates/cart.json` + `main-cart.liquid` with live $117 shipping goal meter)
  5. **Sacred Checkout** (`page.checkout.json` + `main-checkout.liquid` with Shop Pay & free gift sample)
  6. **Order Tracking Sanctuary** (`page.tracking.json` + `main-tracking.liquid` with real-time milestone simulator)
  7. **Radiance Journal (Blog)** (`blog.json` + `main-blog.liquid`)
  8. **Client Care FAQ** (`page.faq.json` + `main-faq.liquid`)
  9. **Clean Philosophy (About Us)** (`page.about.json` + `main-about.liquid`)
  10. **Concierge Studio (Contact)** (`page.contact.json` + `main-contact.liquid`)
- **Interactive Live Preview:** Open `shopify-preview.html` in any web browser to test all pages, interactive cart logic, and animations without requiring a live Shopify store.

## Installation in Shopify

1. In Shopify Admin, navigate to **Online Store > Themes > Add Theme > Upload zip file**.
2. Select `Aura-Beauty-Shopify-Theme-Complete.zip` from the GitHub Releases tab.
